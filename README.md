# MexicanV5 — Ojea

TikTok-style short video app for **Mexico**, in **Spanish (es-MX)**.

Fork concept of [ZyeuteV5](https://github.com/brandonlacoste9-tech/ZyeuteV5) (Québec / fr-CA).

## Brand
- Name: **Ojea**
- Locale: `es-MX`
- Timezone: `America/Mexico_City`
- Cities: CDMX, Guadalajara, Monterrey, Puebla, Tijuana, Mérida

## Run
Open `index.html` or:

```bash
npx serve .
```

## What this is
Frontend demo (feed, explore, create, login).  
Full stack (Supabase, Redis, video pipeline) still needs a separate Mexico backend — do not reuse Zyeuté production keys.
